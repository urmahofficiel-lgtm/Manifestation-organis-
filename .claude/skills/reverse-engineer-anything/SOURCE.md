Compétence copiée depuis https://github.com/morluto/rea (dossier `.agents/skills/reverse-engineer-anything`),

Cette compétence ne contient que des instructions. Pour l'utiliser vraiment, il faut aussi le serveur MCP REA
(`npx rea-agents setup`) et, pour les binaires natifs, un moteur d'analyse (Ghidra, Hopper ou IDA).
Elle ne sert pas pour le code source d'Agora lui-même : elle est prévue pour analyser des logiciels livrés
(applications, sites, binaires) dont on n'a pas le code.
